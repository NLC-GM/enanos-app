# App Enanos: React Native Expo

## Cómo correrla
```bash
npm install
cp .env.example .env
```
Editar `.env` con la IP de la PC donde corre el backend:
```
EXPO_PUBLIC_API_URL=http://TU_IP_LOCAL:3000
```
Luego:
```bash
npx expo start
```
El celular y la PC tienen que estar en la misma red.

Backend: https://github.com/NLC-GM/enanos-backend
